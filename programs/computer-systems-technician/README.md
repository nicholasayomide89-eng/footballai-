# Computer Systems Technician (CST) — program site

A self-contained web page (`index.html`, no build step) built from the CST
certificate program outline. It opens in any browser.

- **Program pages** — overview, Inuit Qaujimajatuqangit principles, careers,
  the 12 learning outcomes, all 11 courses by semester (hours and credits),
  field placement, admission and graduation requirements.
- **Application form** — five steps: personal information, education and
  eligibility (standard or Prior Learning Assessment route), letter of
  interest (150-word minimum), two non-family references with interview
  preference, and a review with declaration.
  - Checks the 17+ age rule, required fields, emails, and flags references
    described as family members.
  - The PLA route asks for a resume, an employer/community reference letter
    and a work-history summary.
  - The draft is saved in the browser as you type; submitting produces a
    reference number and a print / save-as-PDF view.

The form does not send data anywhere — there is no backend. To receive
applications online, connect the submit step to a form service or server.
